# Референсы эргономичного программирования

## Использование

Используй релевантные референсы для получения дополнительного контекста, прояснения терминов, поиска примеров и сверки решений, идей и предложений с реальным кодом.
ЭП всё ещё в разработке; материалы и код могут содержать уже отброшенные примеры, идеи и решения.
Не считай найденное автоматически актуальным правилом ЭП, особенно если это было написано более 6 месяцев назад; при сомнениях уточняй актуальные правила у пользователя.

## Публичные ресурсы

- [Ergowiki](https://ergowiki.azhidkov.pro/) — терминология, принципы, модели, методики и шаблоны Эргономичного подхода.
  Для прояснения понятий начинай с «Терминологии», для поиска решений — с соответствующего раздела бокового оглавления.
- [Блог](https://azhidkov.pro/posts/) — развёрнутые статьи об архитектуре, тестировании и реализации проектов, включая Trainer Advisor.
  Ищи по теме в хронологическом списке постов с пагинацией; статьи содержат пояснения и ссылки на код.
- [Телеграм-канал](https://t.me/ergonomic_code) — заметки и обсуждение идей о поддерживаемых бэкендах, TDD, функциональном программировании и архитектуре.
  Ищи по ключевым словам в канале или [экспорте от 23.10.2026](../../references/ergonomic_code_261023/result.json), учитывая дату и соседние сообщения.
- [Project Mariotte](https://github.com/ergonomic-code/Project-Mariotte) — минималистичный демонстрационный сервис бронирования номеров: доменная модель, операции, HTTP API и тесты.
  Начинай с «Карты проекта» в `README.adoc`: она связывает идеи с конкретным кодом; далее там же описаны требования, API и схемы системы.
  Поидеи должен быть витриной актуальной версии ЭП, но всё равно надо следить за датами и согласованностью с другими свидетельствами.
- [Trainer Advisor](https://github.com/ergonomic-code/Trainer-Advisor) — информационная система йогатерапевта и демонстрационный проект Эргономичного подхода.
  Начинай с `README.md`, затем смотри приложение в `app/`, сквозные тесты в `e2e-tests/` и примеры HTTP-запросов в `requests/`.
  Значительная часть кода (но не весь, в целом можно ориентироваться на фичи интеграции с Яндекс.Формами, Google Calendar и пуш уведомлений) приведена к актуальной версии ЭП.

## Локальные ресурсы

Найди основной ворктри через `git worktree list --porcelain` и прочитай его `local-references.md`, если файл есть.
Этот файл содержит ссылки на локальные копии публичных ресурсов и дополнительные репозитории.
Для чтения материалов и проверки кода предпочитай доступную локальную копию.
