# Ошибочные ответы HTTP JSON API

- Для новых тел ошибочных ответов в Spring 6+ используй `org.springframework.http.ProblemDetail`.
- Добавляй дополнительные поля контракта через свойства `ProblemDetail` или его подкласс.
- Если контекст проекта задаёт собственный или устаревший тип тела ошибочного ответа, используй его вместо `ProblemDetail`.
- Не меняй существующий формат тела ошибочного ответа только ради соответствия этому соглашению без запроса пользователя.
