# Документация HTTP API

- В описании метода кратко объясняй, для чего и как его использовать на семантическом уровне; в тривиальных случаях опускай пояснение.
- Не пересказывай в описании метода сведения о передаче запроса и структуре ответа, уже выраженные формальным контрактом и отображаемые Swagger или его аналогом.
- Не включай детали реализации и незначительные для использования подробности.
- Сверх описания использования добавляй только пояснения об ошибках использования, вероятность которых высока либо ущерб от которых высок и последствия трудно устранить.

Сохраняй полноту формального HTTP-контракта: параметров, схем запросов и ответов, кодов ответа.
