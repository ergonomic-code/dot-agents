# Версионирование HTTP API в Kotlin

- При добавлении N+1-ой версии существующего HTTP эндпоинта следуй алгоритму:
  1. добавить копию текущей реализации с суффиксом `V<N>`.
  2. клиентов (в том числе тесты), которые **должны** остаться на версии N переведи на API из шага 1.
  3. приведи текущую реализацию в соответствие с требования к версии N+1.
  4. переведи всех остальных клиентов на новое API
