# Чек-лист разработки через тесты

- Для каждого написанного или дополненного при изменении поведения теста в текущей сессии наблюдался переход от падения по ожидаемой причине к успешному прохождению либо выполнены все проверки ниже:
  - Временное нарушение проверяемого поведения в продакшн-коде вызвало падение теста по ожидаемой причине.
  - Продакшн-код возвращён в состояние до временного изменения независимо от результата запуска теста.
  - После восстановления продакшн-кода тест успешно прошёл.
