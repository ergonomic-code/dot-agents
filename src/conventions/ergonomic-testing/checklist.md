# Чек-лист Эргономичного тестирования

- Тесты проверяют наблюдаемое поведение через публичное API системы.
- Тестовые дубли используются только там, где реальные зависимости нельзя запустить локально или нужное поведение сложно вызвать штатно в пределах бюджета теста.
- Тесты не проверяют поведение стороннего кода.
- Фактическое время выполнения тестов соответствует ограничениям раздела «Скорость».
