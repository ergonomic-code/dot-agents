# Общая философия тестирования Эргономичного подхода

## Границы и зависимости

- Предпочитай классическую школу тестирования: проверяй наблюдаемое поведение через публичное API системы.
- Предпочитай реальные зависимости.
  Используй тестовые дубли только для систем, которые нельзя запустить локально, или для поведения зависимости, которое сложно вызвать штатными средствами в пределах бюджета теста.
- Не пиши тесты, которые проверяют поведение стороннего кода.

## Скорость

- Обеспечивай среднее время выполнения теста в наборе на текущей машине в пределах более 50 мс.
- Обеспечивай время выполнения отдельного теста вместе с необходимым ему запуском инфраструктуры на текущей машине в пределах 10 с.
