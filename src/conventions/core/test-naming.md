# Test naming

- Use formal mapping when coding from formal case artifacts, aligning existing tests to formal case names, or preserving formal test anchors.
- Preserve existing explicit anchors when naming or aligning a test.
- For formal mapping, recover `Feature`, `Rule`, and an optional named `Example` from explicit anchors, source references, enclosing group names, or verified behavior.
- Stop only when a `Feature` or `Rule` required for formal mapping cannot be recovered confidently.
- Preserve raw `Feature`, `Rule`, and named `Example` text: do not paraphrase, normalize, translate, shorten, re-punctuate, or inflect it.
- Keep the human name connected to the selected SUT; use the loaded feature-naming rules for its SUT reference.
