# Чеклист покрытия требований

Этот чеклист помогает найти пропущенные случаи: достаточно ли выбранных сценариев для проверки требования к поведению из `Rule`.
Применяйте его к набору случаев одного `Rule`: отдельным `Example` и строкам `Examples` в `Scenario Outline` вместе.
Корректность и понятность описания самих сценариев проверяйте по `specification-checklist.md`.
Проверяйте только пункты, относящиеся к требованиям из этого `Rule`.

- Проверены значимые сочетания классов входных данных и состояния SUT, а также способов получения этого состояния, если они влияют на результат.
- Для условий и порогов, при которых меняется ожидаемое поведение, проверены случаи по обе стороны границы и на самой границе.
- Подобраны случаи, которые выявят типичные ошибки: например, возврат одного и того же результата для любых данных или обработку только одного допустимого варианта.
- Проверены требования к составу, порядку и количеству элементов результата.
- Проверено, что результат содержит обязательные данные и не содержит запрещённых.
- Проверены требуемые изменения состояния и побочные эффекты, например отправка уведомления.
- Проверены условия отказа и сообщаемые причины; после отказа нет изменений и побочных эффектов, запрещённых требованиями.
- Проверены свойства, которые должны сохраняться после действия, например неизменность общей суммы при переводе между счетами.
- Проверены требования к формату значений, например к точности суммы или представлению даты.
- Нет случаев, которые повторяют ту же проверку на других данных, не помогая обнаружить дополнительные ошибки.

## Пример проверки покрытия

Требование: заказ стоимостью от 1000 рублей доставляется бесплатно, для остальных стоимость доставки составляет 100 рублей.
Для `Scenario Outline` расчёта доставки значимы следующие наборы параметров:

| Стоимость заказа | Ожидаемая стоимость доставки | Что проверяет случай |
| --- | --- | --- |
| 999 рублей | 100 рублей | Сумма ниже порога |
| 1000 рублей | 0 рублей | Сам порог включён в бесплатную доставку |
| 1001 рубль | 0 рублей | Сумма выше порога |

Один случай на 1000 рублей не выявит реализацию, которая всегда назначает бесплатную доставку или предоставляет её только при точном совпадении с порогом.
