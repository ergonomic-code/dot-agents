# Примеры оформления

Образцы используют Gherkin; показанные отступы и пустые строки не являются дополнительными требованиями фреймворка.

## Именованный пример со ссылкой на источник

```gherkin
Feature: <проверяемый объект> (<SUT-ссылка>)

  Rule: <необязательные условия и обязательные требования к поведению>
    Example: <имя класса входных данных или контекста>
      # <commit>:<relative-file-path>:<line-number>
      Given <значимое условие>
      When <действие или событие, вызывающее проверяемую реакцию>
      Then <наблюдаемый результат>
```

## Пример для генерируемых данных

Для функции `sortNumbers`, сортирующей список чисел:

```gherkin
Feature: Функция сортировки чисел (sortNumbers)
  Rule: должна возвращать исходные числа по возрастанию без потерь и повторного добавления
    Example: произвольный конечный список целых чисел
      Given произвольный конечный список целых чисел
      When список сортируется
      Then числа расположены по возрастанию
      And каждое число встречается столько же раз, сколько в исходном списке
```

Здесь `Given` задаёт область генерации, а `Then` и `And` — свойства результата для каждого сгенерированного списка.
Образец параметризованного кейса приведён в `scenario-outline.md`.
