# Параметризованные сценарии

## Общий шаблон

Используйте `Scenario Outline` для описания параметризованного тестового метода, а строки `Examples` — для наборов параметров отдельных запусков.
Разные последовательности действий или независимые требования к поведению не объединяйте в один шаблон.

## Наборы параметров и ожидаемые результаты

Не оставляйте пустые таблицы `Examples`.
Указывайте различающиеся ожидаемые результаты параметрами шаблона.
Не сворачивайте выбранные наборы параметров в один абстрактный класс и не добавляйте неподтверждённые комбинации.

## Расширение существующего сценария

При расширении сохраняйте существующие строки и добавляйте недостающие без дублирования.

## Пример

Для метода `Order.total`, рассчитывающего стоимость без скидок и дополнительных сборов:

```gherkin
Feature: Метод расчёта стоимости заказа (Order.total)
  Rule: должен возвращать сумму стоимости товаров
    Scenario Outline: разное количество одинаковых товаров
      Given заказ содержит <количество> товаров по <цена> рублей
      When рассчитывается стоимость заказа
      Then стоимость равна <сумма> рублей

      Examples:
        | количество | цена | сумма |
        | 1          | 100  | 100   |
        | 3          | 100  | 300   |
```

Это один тестовый метод с двумя запусками и разными ожидаемыми результатами.
При добавлении случая с двумя товарами сохраните обе строки и добавьте `| 2 | 100 | 200 |`.
