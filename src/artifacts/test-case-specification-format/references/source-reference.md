# Ссылка на источник

Используйте эту ссылку, когда сценарий должен сохранять расположение исходника теста или другой строки с доказательством.

Прикрепляйте не более одной ссылки на источник к одному блоку `Example` или `Scenario Outline`.
Считайте её метаданными, а не шагом сценария.
В исходном тексте Gherkin размещайте машинную форму как комментарий внутри соответствующего сценария перед его шагами.
Если расположение исходника неизвестно, опускайте ссылку.

## Поля

- `<commit>`: конкретная ревизия исходника.
Предпочитайте явно предоставленную ревизию.
В остальных случаях предпочитайте короткий хеш текущей ревизии `HEAD`.
- `<relative-file-path>`: путь к файлу исходника относительно каталога целевого файла артефакта, если этот каталог известен.
В остальных случаях используйте путь к исходнику относительно репозитория.
- `<file-name>`: базовое имя `<relative-file-path>`.
- `<line-number>`: строка объявления метода исходного теста или другая явно предоставленная стабильная строка исходника.
  Не подставляйте вместо `<line-number>` имя метода или любой другой идентификатор.
  Прочитайте исходный файл, чтобы найти точный номер строки.
  Если его нельзя определить, используйте машинную форму вместо понятной человеку формы.

## Пример исходных данных

В примерах ниже тест объявлен в строке `42` файла `../../src/test/kotlin/OrderTest.kt` в ревизии `a1b2c3d`.
Путь указан относительно каталога спецификации.

## Машинная форма

Используйте машинную форму в простом тексте артефакта и всегда, когда нельзя корректно оформить кликабельную ссылку.

```gherkin
Example:
  # a1b2c3d:../../src/test/kotlin/OrderTest.kt:42
  Given заказ не содержит товаров
  When рассчитывается стоимость заказа
  Then стоимость равна нулю
```

## Форма для человека

Используйте понятную человеку форму только когда выбранный формат поддерживает кликабельные ссылки и путь к целевому файлу артефакта известен.
Размещайте её вне блока исходного текста спецификации, сохраняя однозначную привязку к сценарию.

В Markdown:

```md
[a1b2c3d:OrderTest.kt:42](../../src/test/kotlin/OrderTest.kt)
```

В AsciiDoc:

```adoc
link:../../src/test/kotlin/OrderTest.kt[a1b2c3d:OrderTest.kt:42]
```

Сохраняйте адрес ссылки равным `<relative-file-path>`.
Оставляйте в видимом тексте только базовое имя: `<commit>:<file-name>:<line-number>`.
Когда понятную человеку форму нельзя корректно оформить, используйте машинную форму вместо того, чтобы придумывать или опускать ссылку на источник.
