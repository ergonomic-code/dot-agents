# Ссылка на источник

Используйте эту ссылку, когда правило или пример должен сохранять расположение исходника теста или другой строки с доказательством.

Прикрепляйте не более одной ссылки на источник к одному блоку `Rule` или `Example`.
Если расположение исходника неизвестно, опускайте ссылку.

## Поля

- `<commit>`: конкретная ревизия исходника.
Предпочитайте явно предоставленную ревизию.
В остальных случаях предпочитайте короткий хеш текущего checked-out `HEAD`.
- `<relative-file-path>`: путь к файлу исходника относительно каталога целевого файла артефакта, если этот каталог известен.
В остальных случаях используйте путь к исходнику относительно репозитория.
- `<file-name>`: базовое имя `<relative-file-path>`.
- `<line-number>`: строка объявления метода исходного теста или другая явно предоставленная стабильная строка исходника.
  Не подставляйте вместо `<line-number>` имя метода или любой другой идентификатор.
  Прочитайте исходный файл, чтобы найти точный номер строки.
  Если его нельзя определить, используйте машинную форму вместо понятной человеку формы.

## Машинная форма

Используйте машинную форму в простом тексте артефакта и всегда, когда нельзя безопасно вывести кликабельную ссылку.

```text
# <commit>:<relative-file-path>:<line-number>
```

## Форма для человека

Используйте понятную человеку форму только когда контейнер вывода поддерживает кликабельные ссылки и путь к целевому файлу артефакта известен.

В Markdown:

```md
[<commit>:<file-name>:<line-number>](<relative-file-path>)
```

В AsciiDoc:

```adoc
link:<relative-file-path>[<commit>:<file-name>:<line-number>]
```

Сохраняйте адрес ссылки равным `<relative-file-path>`.
Оставляйте в видимом тексте только базовое имя: `<commit>:<file-name>:<line-number>`.
Когда понятную человеку форму нельзя безопасно вывести, используйте машинную форму вместо того, чтобы придумывать или опускать ссылку на источник.
