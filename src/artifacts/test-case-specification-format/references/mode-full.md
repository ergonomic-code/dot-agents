# Полный режим

Используйте этот режим для исполнимых или почти исполнимых проверок, проверок, восстановленных по коду, и входных данных для генерации кода.

Выводите `Feature`, `Rule`, `Example`, `Given`, `When`, `Then` и `And`.
У каждого `Rule` есть хотя бы один `Example`.
Используйте `Example` без имени, когда не нужно имя существенно отличающегося класса входных данных или контекста.
`Example` может называть класс входных данных, а не конкретный элемент.
Если у `Rule` есть безымянный `Example`, этот безымянный пример должен быть единственным `Example` в этом `Rule`.
Необязательная строка ссылки на источник может находиться сразу под соответствующим `Example` согласно `references/source-reference.md`.

Помещайте в `Given` только предусловия, значимые для результата.
Описывайте каждое предусловие как состояние, существующее до проверяемого действия.
Для примера, описывающего класс входных данных, указывайте его область в `Given` и инвариант в `Then`, не выбирая конкретные элементы.
Не включайте предыдущее действие только для установления этого состояния; включайте его, только когда выбранная обязанность делает последовательность действий наблюдаемым поведением.
Описывайте подготовку конкретными предметными объектами, состояниями и литералами, только когда они существенно влияют на пример.
Помещайте проверяемое действие в `When`.
Предпочитайте одно действие в `When`.
Добавляйте второе действие, только когда выбранная обязанность делает последовательность наблюдаемым поведением, включая явное чтение после записи.
В проверках команд с чтением после записи и публичной операцией наблюдения помещайте команду в `When`, а операцию наблюдения — в `And`.
Если возвращённые командой данные нужно проверить до наблюдения, используйте `When`, `Then`, `And`, `Then`: команда, результат команды, операция наблюдения, наблюдаемое состояние.
Если нужны несколько вызовов конечных точек наблюдения, помещайте каждое действие наблюдения в отдельный следующий `And`, а его результат — в следующий `Then`.
В остальных случаях оставляйте оба действия перед `Then`.
В других составных потоках помещайте первое действие в `When`, а каждое последующее — в следующий `And`.
Помещайте в `Then` и продолжающие `Then` строки `And` только наблюдаемые результаты, побочные эффекты, отказы, гарантии порядка и гарантии кардинальности.
Не сопровождайте положительный результат зеркальным утверждением об отсутствии альтернативного результата, если это отсутствие не является отдельной контрактной обязанностью.
Используйте `And` только для продолжения предыдущего типа шага, кроме `And` наблюдения после записи и `Then` с результатом команды.
