# Краткий режим

Используйте этот режим для кратких чеклистов требований и других намеренно неисполнимых списков проверок.

Выводите только `Feature`, `Rule` и необязательный именованный `Example`.
Если у `Rule` в `full` ровно один безымянный `Example`, опускайте этот `Example` в `short`.
Необязательная строка ссылки на источник может находиться сразу под `Rule`, если `Example` не выводится, или сразу после его именованного `Example` согласно `references/source-reference.md`.
Не выводите `Given`, `When`, `Then` или `And`.

Именуйте `Rule` по проверяемому свойству.
Используйте `Example` только для существенно разных классов входных данных или контекста одного `Rule`.
Выбирайте примеры, которые выявили бы реализацию для одного случая, захардкоженную или переобученную реализацию.
Предпочитайте семантические классы литералам: по умолчанию/не по умолчанию, пустой/непустой, присутствует/отсутствует, совпадающий/несовпадающий, граничный/обычный, валидный/невалидный.
Предпочитайте минимальный полный набор примеров.
Не сохраняйте детали примера, если их исключение не потеряет смысл контракта.
