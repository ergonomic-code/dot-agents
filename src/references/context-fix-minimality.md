# Минимальность контекста и исправлений

В файлах контекста агента:

- Оставляй только инструкции, влияющие на поведение.
- Удаляй повторы, мотивацию, необязательные предпочтения и примеры, которые не добавляют нового правила.
- Предпочитай удаление, сокращение, объединение повторное использование и точечные изменения расширению текста.
- Предпочитай небольшие тематические файлы или справочники разрастанию общего файла.
- Если краткость противоречит надёжности, выбирай самую короткую формулировку, которая сохраняет надёжное поведение.
