# Первоначальная настройка тестов HTTP-границы

Для первого кейса настрой тестовый HTTP-транспорт, определи `ApiSession` и фабрику сессий, затем добавь доменный API с единственной необходимой операцией.
В кейсе получи сессию участника через фабрику, создай или получи связанный с ней доменный API и вызови его типизированный метод.
Конкретные типы транспорта, способ доступа к API и регистрацию инфраструктуры возьми из паттернов своего стека.
