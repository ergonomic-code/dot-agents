# Spring context

Load only the entries matching the requested or planned Spring work:

- Spring JDBC access or row mapping: `../conventions/spring-jdbc.md`;
- Spring-managed dependency wiring: `../conventions/spring-dependency-injection.md`;
- Kotlin use of Spring APIs: `../conventions/spring-kotlin.md`;
- registration of a Spring-managed component or bean: `../conventions/spring-bean-registration.md`;
- Spring HTTP JSON API error handling or error-body contracts: `../conventions/spring-http-json-api.md` and `../patterns/http-json-api/error-response-body-format.md`.

Project-specific Spring MVC handler rules remain project-local context and are loaded through project `AGENTS.md` when declared there.
