# AGENTS.md

## Назначение

Этот файл регулирует работу над самим фреймворком.
Работа над контекстом фреймворка создаёт и изменяет файлы, которые регулируют работу агентов в целевом репозитории.

## Язык контекста фреймворка

Пиши контекст фреймворка на русском.
Пиши новые контекстные файлы фреймворка на русском.
При изменении существующего контекстного файла фреймворка переводи на русский весь его человекочитаемый текст, включая неизменённые фрагменты.
Не переводи технические идентификаторы, пути, код, команды, ключи форматов, имена API и дословные контрактные значения, если перевод изменит их смысл или нарушит работоспособность.
Фреймворк находится в процессе постепенного перевода с английского на русский, поэтому не затронутые текущей работой файлы могут оставаться на английском.

## Краткость

Ставь корректность, необходимый контекст и проверяемость выше краткости.
После выполнения этих требований пиши кратко.
Предпочитай более короткие формулировки и меньшее количество разделов, если это не удаляет необходимые свидетельства, оговорки или инструкции.
При изменении файлов фреймворка предпочитай минимально достаточную правку и не добавляй предупредительные правила без необходимости.

## Управляющие файлы фреймворка

Управляющие файлы фреймворка находятся в `.agents/`.
Для исправления контекста фреймворка используй `.agents/skills/fix-framework-context/SKILL.md`.
Файлы под `src/` не являются активными управляющими файлами фреймворка.

# Соглашения Markdown

## Одно предложение на строку

В прозаических абзацах:
- каждое предложение начинается с новой строки;
- списки состоят из коротких пунктов;
- длинные блоки разбиваются на подпункты.

## Компактное форматирование

Форматируй Markdown компактно.
Используй пустые строки только между заголовками и абзацами.
Не разделяй предложения пустыми строками.

Но при этом разделяй текст на целостные абзацы.
Один абзац может состоять из одного длинного, логически целостного предложения.

Запускай тесты Python с помощью `pytest`.
