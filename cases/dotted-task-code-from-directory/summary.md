# Код задачи с точками из имени директории

## Свидетельства

Сессия: `01a12fcd-d129-7f82-a005-185f6c5e3fdd`.
Исходный запрос пользователя:

```text
371-1

/$design-test-case

g04
```

В стартовом контексте были baseline, протокол маршрутизации, конфигурация и скилл `design-test-case`.
Агент передал запрос загрузчику дословно; тот вернул `Active task: none`.
Агент затем самостоятельно нашёл бриф подзадачи в devlog.
Ожидалось, что загрузчик найдёт указанную подзадачу и выдаст её контекст.

## Подтверждённая причина

В devlog одновременно находились директории `371-portal-contract` и `371-1-refactor-user-roles` с брифами без `task_id`.
Резолвер определял обе как `371`, после чего исключал их как дубликаты.
Код `371-1` отсутствовал среди кандидатов.
Это дефект определения кода задачи, а не маршрутизации контекста.
Текущий шаблон брифа и инициализатор также не записывали метаданные, которые использовал резолвер для составных кодов.

## Выбранное исправление

Пользователь изменил требование: «ок, давай по другому - точки допустить, а task_id вообще убрать».
Затем подтвердил использование точек вместо дефисов внутри кода.
Код определяется только по имени директории до первого дефиса; группы букв и цифр разделяются точками.
Чтение YAML-метаданных удалено, правила инициализации и документация согласованы с резолвером.
Так граница кода и slug однозначна и не зависит от содержимого брифа.

```text
371-portal-contract     -> 371
371.1-refactor-user-roles      -> 371.1
371-1-refactor-user-roles      -> 371
```

Старый запрос `371-1` больше не является допустимым кодом.
Для использования кода подзадачи требуется переименовать её директорию в `371.1-refactor-user-roles`, обновить ссылки и передавать `371.1`.
Директории целевого проекта в этом исправлении не изменяются.

## Проверка

Регрессионные тесты проверяют раздельный выбор родительской задачи и подзадачи, загрузку полного контекста, независимость от метаданных, отказ для некорректных и частичных кодов, исключение дубликатов и сохранение существующих способов передачи кода.
