# Коды файлов вне загруженного контекста задачи

## Обстоятельства и запросы

При работе над активной задачей агент создавал дополнительные файлы.
Релевантные запросы пользователя, обобщённый пересказ:

- Выполнить работу по задаче и подготовить рабочие материалы.

## Свидетельства и причина

Агент прочитал `src/task-workdir/entrypoint.md` и вызвал загрузчик контекста задачи.
Загрузчик нашёл активную задачу и вернул общие правила, включая указание прочитать `references/development-process.md` для работы с артефактами разработки.
Вызова чтения этого справочника в сессии нет.
Агент создал файлы с префиксами `050`–`053`, хотя справочник определял только коды `010`, `020`, `030` и `040` по назначению артефакта.
Источник выбранных кодов в сессии не указан; предположение о последовательной нумерации не подтверждено.

Наблюдаемая ошибка — пропуск чтения зависимости с правилами именования.
Классификация файлов находилась за дополнительным переходом, хотя создание материалов разрешалось уже загруженным контекстом.
Вывод загрузчика также был усечён инструментом; ссылка на справочник сохранилась в видимой части, поэтому усечение не объясняет пропуск её чтения.

## Ожидаемое поведение

Агент выбирает код по назначению файла, а не по порядку создания.
Для рабочих файлов реализации используется `040`.
Обезличенный пример наблюдаемого имени: `050-material.txt`.
Целевое имя, реконструкция: `040-material.txt`.
Несколько рабочих файлов различаются содержательной частью имени и сохраняют код `040`.

## Исправление

Классификация кодов перенесена из справочника процесса в автоматически загружаемый `context.md` без дублирования.
Уточнено, что выбор определяется назначением файла и ограничен перечисленными кодами.
Справочник и README ссылаются на новое место правил.
В `entrypoint.md` добавлено требование сохранять stdout при вызове загрузчика и читать его полностью, при усечении — частями без повторного запуска.
Загрузчик и распределение ответственности компонентов не изменены.

## Проверка

Существующие тесты загрузчика: `PYTHONDONTWRITEBYTECODE=1 pytest -q -p no:cacheprovider tests/test_load_task_context.py` — 16 passed.
Проверка на временной задаче подтвердила включение полного `context.md` с кодами перед брифом в реальный вывод загрузчика.
Проверены новые ссылки и целевой заголовок; `git diff --check` прошёл.
Эти проверки подтверждают доставку правил и структуру изменения; соблюдение инструкции агентом в новой рабочей сессии ими не доказано.

## Влияние

Новых возможностей, зависимостей и шагов установки нет.
README синхронизирован, поскольку изменилось документированное место классификации кодов.
